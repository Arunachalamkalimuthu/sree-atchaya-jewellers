# Sree Atchaya Jewellers: design preview

A clickable demo website and phone app concept for a Coimbatore jeweller. All data is sample data.
This is **not** the official website: every page carries a preview ribbon, is `noindex`, and `robots.txt` disallows all.

- `npm run dev` for local development.
- `npm test` runs the unit tests (vitest).
- `GITHUB_PAGES=true npm run build` produces the static export in `out/` (served under `/sree-atchaya-jewellers`).
- Pushing to `main` deploys to GitHub Pages via `.github/workflows/pages.yml`.
